Clayton — a toolkit for RNG manipulation in the Pokémon HeartGold/SoulSilver Safari Zone.

| Download | Platform | Status |
|---|---|---|
| `Clayton-windows.exe` | Windows | tested |
| `Clayton-macos` | macOS | **untested** |
| `Clayton-linux` | Linux | **untested** — needs GTK 3 and WebKitGTK already on your machine; the Nix package is the better route there |

Each file is a single self-contained executable: download it, and on macOS or Linux make it
executable (`chmod +x Clayton-macos`) before running.

Windows and macOS will warn that the publisher is unrecognised, because these builds are
unsigned. On Windows choose **More info** → **Run anyway**; on macOS right-click → **Open**.

Your data lives outside the executable, so replacing it with a newer build never touches your
profiles, runs or charts.

See the [user guide](https://github.com/Testare/clayton/tree/main/guide) to get started.
