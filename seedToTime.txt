Creating a script to generate times from a key seed:
A key seed is an 8-digit hexadecimal number like `0xf519083F`
The key seed will be divided into 3 parts:
The first 2 digits (`(key_seed & 0xFF000000) >> 24`) are used to determine valid month-day-minute-second combinations. I'll refer to this as the mdms.
The last 4 digits (`key_seed & 0x0000FFFF`) is the delay, not part of the time per-se but should be returned by the script as well.
The next 2 digits (`(key_seed & 0x00FF0000) >> 16`) is the hour (on a 24 hour clock.)
Year will be assumed to be 2000.

To generate possible dates, first load the mdMap from `./mdMap.json` mdms2 by taking `(mdms + 137) % 255`. If mdms2 > mdms, then take the first **mdms** elements of the mdMap and the last **mdms2** elements, then combine them for the "mdList". If mdm2 < mdms (it should never be equal), then take elements from index mdms2 to mdms inclusive for the mdList.

The mdList contains a list of possible months and days for the seed, formatted as a pair [month day]. For each one, calculate (255 + mdms - (month * day)) % 255. this is our minuteSecond. We should generate all possible combinations of second and minute that add up to this number. We now have all possible times for the seed, so we should format it as a string and add it to a master list.

Output of script should be a json object with a schema like so:
`{"delay": <delay>, "date-times": ["2000-05-26 19:56:59"], "2000-05-26 19:57:58", <other date times>]}`
