# Held Items

We can use Held Items to help make compass more successful, though fling makes things more complicated

## Lagging Tail

P0 - Probably the best way to mitigate the chance of additional randomness due to speed ties

## Choice Scarf

P3 - Can help cover for some things

## Iron Ball/Power Belt/Power Bracelet/etc.

P3 - Lowers user's speed significantly, which can help underspeed even Lvl 2 Magikarp. These items are not as easy to obtain as lagging tail is.

## Sitrus Berry

P3 - Doesn't help with speed ties, but can help increase survivability for very low level pokemon.
