# Transform

Metronome CAN call Transform. This copies many things about the opponent, including stat changes and moves (Though thankfully not status conditions). Copying moves means our metronome user is no longer a metronome user.

In addition to adjusting abilities, this means we can no longer select metronome, but have to select one of the moves Magikarp knows. If the Magikarp is below level 15, we effectively only have splash, and there isn't any more observable RNG.

If Magikarp is above level 15, we can use tackle and get some RNG from crits or misses perhaps. We would have to implement logic to handle our metronome user now being a Magikarp. But the only mitigation for below Level 15, and probably a better mitigation in general, is just to support switching out.
